# Petey Plant Blender models

This is the shared model folder. Open the editable Blender file for geometry, materials, animation controls and studio camera. The nearby spec links the runtime GLB and transparent WebP preview. For every future model, save its Blender file under `assets/characters/<asset-id>/source/`, create its spec, and update this index. Use the [export and QA workflow](../../tools/blender/README.md).
